# Эксперименты

Всё, что пробовали за неделю, с цифрами. Каждая папка — точка входа `predict.py` в том виде,
в каком она уходила на платформу. Собрать её в архив:

```bash
python tools/pack_experiment.py experiments/j3_cascade dist/j3_cascade.zip
```

Упаковщик добавит модули и промпты из `solution/`, промпты из `experiments/prompts/` и эвристики
графа из `experiments/graph_signals/`. Эксперименты скачивают веса с Hugging Face при запуске:
для лидерборда это работало, для финала по правилам — нет (см. корневой README).

## Сабмиты на лидерборд (открытый тест, 548 ответов, 130 галлюцинаций)

Платформа показывает F1, precision и recall, поэтому для любого сабмита точно восстанавливается
число помеченных ответов и найденных галлюцинаций: найдено = R·130, помечено = найдено / P.

| Сабмит | Папка | Идея | Помечено | Найдено | P | R | F1 |
|---|---|---|---|---|---|---|---|
| бейзлайн организаторов | — | один токен, P ≥ 0.5 | 254 | 94 | 0.370 | 0.723 | 0.4896 |
| всё = 1 | `rules_probe` (MODE=all1) | зонд: сколько в тесте галлюцинаций | 548 | 130 | 0.237 | 1.000 | 0.3835 |
| правила | `rules_probe` (MODE=rules) | «есть вызов инструмента» или сигнал графа | 179 | 38 | 0.212 | 0.292 | 0.2460 |
| топ-30% | — | бейзлайн, порог по доле вместо 0.5 | 169 | 69 | 0.408 | 0.531 | 0.4615 |
| j2 | `j2_think_ensemble` | промпт v2 + рассуждения, сумма z-оценок, топ-28% | 153 | 69 | 0.451 | 0.531 | 0.4876 |
| j3 | `j3_cascade` | кандидаты бейзлайна → перепроверка рассуждениями v3 | 90 | 52 | 0.578 | 0.400 | 0.4727 |
| j4 | `j4_split` | тексты — бейзлайн, вызовы — рассуждения v3 | 241 | 90 | 0.373 | 0.692 | 0.4852 |
| **final** | `solution/scripts/predict.py` | бейзлайн с логит-разностью, веса в архиве | **263** | **97** | **0.369** | **0.746** | **0.4936** |
| border | `solution/scripts/predict_border.py` | final + рассуждения для ответов чуть ниже порога | — | — | — | — | не зафиксирован |

Для сравнения, первое место: F1 0.643, P 0.560, R 0.754.

Что из этого следует:
- **Правило «есть вызов» на валидации давало F1 0.91, на тесте 0.25.** В валидации 21 из 23
  галлюцинаций — в вызовах инструментов, а на тесте не меньше 92 из 130 — в обычных текстовых ответах.
- **Порог по доле не помогает:** уверенность бейзлайна выше 0.5 почти не отличает настоящие
  ошибки от ложных тревог: в топ-169 по уверенности 69 найденных, а случайные 169 из 254 кандидатов дали бы ~62.
- **Рассуждения повышают точность, но режут полноту.** Каскад дал precision 0.58 — как у лидера, —
  но выбросил 42 из 94 найденных галлюцинаций.
- **Разделение «тексты/вызовы» ничего не дало:** ложные тревоги бейзлайна сидят в текстах, а не в вызовах.
- **По полноте final на уровне лидеров (0.746 против 0.754).** Всё отставание — в ложных тревогах: 166 против ~77.

## Лаборатории (бесплатные проверки)

Упавший запуск попытку не тратит, а при падении на проверочном прогоне (46 строк валидации,
шаг 10) платформа показывает лог. Лаборатории считают метрики на этих 46 размеченных примерах,
печатают их и намеренно завершаются с кодом 3.

**`lab1_prompts`** — промпты и режим рассуждений, AUC на 46 примерах:

| Вариант | AUC | Помечено при P ≥ 0.5 |
|---|---|---|
| бейзлайн, один токен | 0.819 | 23/46 |
| промпт v2 (под формат данных) | 0.893 | 22/46 |
| v2 + напоминание в конце | 0.915 | 22/46 |
| v2 + рассуждения | 0.895 | 18/46 |
| бейзлайн + рассуждения | 0.709 | 11/46 |
| сумма v2_end и v2_think | 0.951 | — |

На тесте прирост не подтвердился: чек-лист v2 писался по пояснениям к этим же 46 примерам,
а они почти все про вызовы инструментов.

**`lab2_cascade_synthetic`** — каскад и 17 синтетических текстовых ошибок (`synthetic.py`:
в верный ответ вносится неверное число, ID, правило или выдуманное действие). Синтетику поймали
все варианты, 17 из 17, — она оказалась слишком лёгкой. На реальных примерах:

| Вариант | Найдено из 23 | Ложных из 23 | Ложных на 21 верном тексте |
|---|---|---|---|
| бейзлайн | 15 | 5 | 3 |
| v3, один токен | 17 | 4 | 2 |
| бейзлайн + рассуждения | 8 | 0 | 0 |
| v3 + рассуждения | 15 | 0 | 0 |
| каскад бейзлайн → v3 + рассуждения | 12 | 0 | 0 |

**`lab3_history_mirror`** — «зеркало теста». Из истории 46 диалогов нарезаны 115 прошлых ходов агента
(54 текста, 61 вызов): контекст до хода плюс сам ход без результатов инструментов. Почти все такие
ходы верные, и по составу они похожи на тест. Проверка калибровки: бейзлайн помечает 39% прошлых
ходов, а на тесте у него 38% ложных тревог (160 из 418).

| Вариант | Найдено из 23 | Ложных из 23 | Помечено прошлых ходов (тексты / вызовы / все) |
|---|---|---|---|
| бейзлайн | 16 | 6 | 37% / 41% / 39% |
| v3 + рассуждения | 17 | 0 | 15% / 26% / 21% |
| v4 + рассуждения (мягкий v3) | 17 | 0 | 13% / 25% / 19% |

v3 и v4 совпали в 157 ответах из 161: ослабление формулировки на модель не действует.

## Разведка платформы

- **`diag`** — окружение: Python 3.12.12, vLLM 0.19.1, torch 2.10.0+cu128, transformers 4.57.1,
  A100-SXM4-80GB, 128 CPU, интернет до Hugging Face, PyPI и GitHub есть. Зависимости из
  `pyproject.toml` не ставятся — можно опираться только на то, что уже есть в окружении.
- **`speedtest`** — скорость Hugging Face с машины платформы: 413 МБ/с через hf_xet, вся модель
  скачивается за ~1.5 минуты. Запуск vLLM с этой моделью — 5 минут; проход судьи по 548 ответам — ~9 минут (пересчёт с замера на валидации).
- **`test_structure_probe`** — попытка посмотреть структуру теста. Падение на тестовом прогоне
  (шаг 16) лога не даёт, так что тест изнутри не подсмотреть.

## Остальное

- **`prompts/`** — `prompt_v2.md` (формат данных + чек-лист ошибок вызовов) и `prompt_v4.md`
  (v3 без фразы «ставь 1, только если можешь указать…»). Действующий v3 лежит в `solution/`.
- **`graph_signals/guard/`** — эвристики без модели: разбор диалога, инструменты вне
  `[AVAILABLE TOOLS]`, ключи вне схемы, повтор упавшего вызова, сущности ответа вне контекста.
  Использовались в `rules_probe` и для разрешения ничьих в j2.
