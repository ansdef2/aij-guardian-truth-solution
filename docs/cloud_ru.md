# Как собрать архив с весами на облачной машине

Финальное решение должно нести веса модели внутри архива: это ~37.5 ГБ. Скачивать и загружать
столько через домашний или мобильный интернет нереально, поэтому архив собирается на машине
в облаке и загружается на платформу из её браузера. Ниже — путь, который сработал на
Cloud.ru Evolution (личное облако, стартовый грант 4000 бонусов), со всеми граблями, на которые
мы наступили.

> Видеокарта на этой машине не нужна: модель здесь не запускается, машина только скачивает
> файлы, пакует их и отправляет. Модель работает потом, на A100 платформы.

## 1. Машина

Консоль Cloud.ru → «Инфраструктура» → «Виртуальные машины» → «Создать»:

| Параметр | Значение |
|---|---|
| Образ | публичный Ubuntu 22.04 (Windows в публичных образах Evolution нет) |
| Ресурсы | 4 vCPU, 16 ГБ RAM, без GPU (~3 800 ₽/мес ≈ 5 ₽/час) |
| Диск | SSD 150 ГБ (веса 35 + архив 37 + система) |
| Публичный IP | назначить |
| Группа безопасности | входящее TCP 3389 (RDP) и **исходящий трафик целиком** |
| Логин и пароль | задать в защищённой форме при создании |

**Грабли:** без исходящего правила в группе безопасности машина не видит интернет вообще,
и `apt` падает с `Could not resolve`.

## 2. Рабочий стол

Через «Виртуальную консоль» в браузере (вставка там не работает — команды набираются руками):

```bash
# внутреннее зеркало пакетов из образа снаружи не резолвится — переключаемся на Яндекс
sudo sed -i 's#https://repo.mng.sbercloud.tech/repository#http://mirror.yandex.ru#' /etc/apt/sources.list
sudo apt update
sudo apt install -y xfce4 xfce4-terminal dbus-x11 xrdp falkon python3-venv unzip git
```

Если посреди установки появится окно «Which services should be restarted?» — Enter.

Дальше подключение со своего компьютера: Windows — `mstsc`, IP машины, логин и пароль;
macOS и телефон — приложение Windows App. На рабочем столе уже работает вставка из буфера.

## 3. Код и веса

```bash
git clone <ваш репозиторий> && cd <репозиторий>
nohup bash tools/run_all.sh > build.log 2>&1 &
tail -f build.log
```

`nohup` нужен, чтобы обрыв RDP не убил сборку. Окно удалённого стола закрывайте крестиком,
а не через «Выйти» — тогда сеанс и всё запущенное продолжают работать.

Если репозиторий приватный и `git clone` неудобен, код можно перенести архивом через публичную
ссылку Яндекс Диска (Telegram без VPN не открывается) и скачать прямо в терминале:

```bash
curl -s "https://cloud-api.yandex.net/v1/disk/public/resources/download?public_key=<ссылка>" > link.json
curl -L -o code.zip "$(grep -o 'https://downloader[^"]*' link.json)"
```

Скачивание весов идёт 5–20 минут, упаковка — ещё 5–10. В конце: `проверка структуры: ок`
и `ГОТОВО: dist/final.zip`.

## 4. Загрузка на платформу

Встроенный Falkon на Ubuntu 22.04 слишком старый — сайт платформы на нём не стартует
(висит логотип). Нужен свежий браузер:

```bash
sudo snap install firefox
```

В Firefox — платформа → загрузка решения → `dist/final.zip`. Платформа режет файл на ~280 частей
и грузит их по очереди; 37 ГБ с машины уходят примерно за час. Обрывы вашего RDP загрузке
не мешают — она идёт с машины.

## 5. После прогона

Остановить машину (не платить за CPU и память) или удалить её вместе с диском и публичным IP.
Если машина остаётся — закрыть входящее 3389, пока она не нужна.
